## 예약

관리자 설정의 **날짜 및 시간 예약**이 켜져 있으면, 현재 시각에 맞는 **첫 번째 줄**의 효과가
표시됩니다. 시각은 환경설정의 기본 시간대로 계산합니다. 예약 시각이 되면 페이지를 새로고침하지
않아도 효과와 헤더의 켜기/끄기 버튼이 바로 바뀝니다. 예약 범위 안에서만 방문자의 개별 ON/OFF
선택이 반영됩니다.

### 세부 설정은 어디서 오나

효과 종류, 밀도, 낙하 속도, 불투명도, 바람 세기·방향, 입자 색상은 **그 예약 줄에 저장된 값**을
씁니다. 위쪽 기본 설정 카드가 아닙니다.

- 줄에 해당 항목이 비어 있으면 위쪽 기본 설정을 쓰고, 기본 설정도 없으면 플러그인 기본값을 씁니다.
- 예약이 꺼져 있거나 줄이 없으면 위쪽 기본 설정만 씁니다.
- 예약이 켜져 있는데 지금 시각에 맞는 줄이 없으면 효과를 표시하지 않습니다.

### 날짜, 요일, 시간

날짜·요일·시간은 **모두 따로 검사**하며, 조건을 모두 만족해야 켜집니다. 날짜를 넣었다고 요일이
빠지지는 않습니다.

- **날짜만 넣은 경우** (예: 9월 7일~9월 20일): 그 기간 밖에서 꺼지고, 기간 안에서도 체크한
  요일에만 켜집니다. 일~토를 모두 체크하면 기간 안에서는 매일 켜집니다. 월~금만 체크하면 그
  기간의 평일에만 켜집니다.
- **날짜를 비우고 요일만 넣은 경우**: 날짜 제한 없이, 체크한 요일에만 켜집니다. 예: 토·일만
  체크하면 매주 주말입니다.
- **시간을 비운 경우**: 그날 하루 종일입니다. 시간을 넣으면 그 시간대에만 켜집니다.
- 종료 시간이 시작 시간보다 이르면 자정을 넘깁니다. 예: `22:00`~`06:00`은 밤 10시부터 다음 날
  오전 6시까지입니다.
- 요일을 모두 해제하면 날짜가 맞아도 켜지지 않습니다.
